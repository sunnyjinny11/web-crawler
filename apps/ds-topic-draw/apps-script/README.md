# 로그인 없는 버전 (구글 Apps Script)

학생은 링크만 열면 바로 뽑을 수 있다. 구글 계정도, Claude 계정도 필요 없다.
배정 결과는 교수자의 구글 시트에 쌓인다.

## 설치 (교수자 1회, 약 5분)

1. 구글 드라이브에서 새 구글 스프레드시트를 만든다. 이름은 자유 (예: 자료구조 주제 뽑기).
2. 메뉴 확장 프로그램 > Apps Script 를 연다.
3. 기본으로 있는 Code.gs 내용을 모두 지우고, 이 폴더의 `Code.gs` 내용을 붙여 넣는다.
4. 왼쪽 파일 옆 + 버튼 > HTML 을 눌러 이름을 `Index` 로 만들고, 이 폴더의 `Index.html` 내용을 붙여 넣는다.
5. 저장한 뒤 위쪽 함수 선택 칸에서 `setup` 을 고르고 실행을 누른다.
   처음에는 권한 승인 창이 뜬다. 내 계정을 고르고 허용한다.
   실행 로그에 교수자 키가 찍힌다. 메모해 둔다.
   시트에 topics 탭이 생기고 주제 21개가 들어간다.
6. 오른쪽 위 배포 > 새 배포 > 유형 선택에서 웹 앱을 고른다.
   - 다음 사용자 인증 정보로 실행: 나
   - 액세스 권한이 있는 사용자: 모든 사용자
   배포를 누르면 웹 앱 URL 이 나온다.

## 쓰는 법

- 학생용 주소: 웹 앱 URL 그대로. 단축 URL 이나 QR 코드로 나눠 주면 편하다.
- 교수자용 주소: 웹 앱 URL 뒤에 `?admin=교수자키` 를 붙인다. 이 주소로 열면 배정 해제 버튼이 보인다. 학생에게 알려 주지 않는다.
- 주제 추가, 수정, 삭제는 시트의 topics 탭에서 행을 직접 고치면 된다.
  cat 칸은 linear, tree, hash, graph, adv 중 하나. 그 외 값은 기타로 묶인다.
- 처음부터 다시 하려면 시트에서 claimedBy, studentNo, claimedAt 세 열의 값만 지운다.

## 알아 둘 점

- 학교 구글 워크스페이스 계정이면 관리자 설정 때문에 액세스 권한에 모든 사용자 항목이 안 보일 수 있다.
  그럴 때는 개인 Gmail 계정으로 만들면 된다.
- 대시보드는 4초마다 새로 고친다. 뽑기는 서버에서 잠금을 걸고 무작위로 고르므로 동시에 눌러도 같은 주제가 두 번 나가지 않는다.
- 로그인이 없으므로 다른 학생의 학번을 적어 대신 뽑는 것은 막을 수 없다. 문제가 생기면 교수자 화면에서 해제하면 된다.
- 코드를 고친 뒤에는 배포 > 배포 관리 > 수정(연필) > 버전: 새 버전 으로 다시 배포해야 학생 화면에 반영된다.
